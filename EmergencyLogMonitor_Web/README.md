# Emergency Log & Location Monitor

A lightweight, dedicated real-time log monitoring website and server status interface.

---

## 📋 Features

* **Firestore Live Monitor**: Subscribes directly to the `locations` collection in Firebase Firestore and automatically appends cards as coordinates arrive.
* **Server Runtime Log (`backend_log.txt`)**: Contains historical supervisor output logging incoming listener initialization and call detection events.

---

## 🌐 How to Use

Open `index.html` in any browser to inspect the real-time event log and database connection status.
